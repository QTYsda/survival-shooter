# 生存射击（Survival Shooter）

一个用 Unity 做的第三人称生存射击小游戏：玩家在场景里移动、瞄准鼠标方向射击，怪物一波波刷新并追着玩家攻击，击杀得分，血量归零则游戏结束。

这是跟着 Unity 官方 **Survival Shooter** 教程做的练习项目，脚本部分是自己照着重写并加了中文命名，方便对照学习。

## 关于资源文件

**本仓库只包含代码、场景、预制体和工程设置，不包含美术与音效资源。** 模型、贴图、音频、字体等素材来自 Unity 官方的 Survival Shooter 教程，版权不属于本项目，因此没有一并上传。

直接克隆本仓库打开工程时，场景里的模型和贴图会显示为缺失引用（粉色/空白），这是正常的。想完整运行，请自行从 Unity 官方教程资源里导入这些素材，或在 `Assets/` 下替换成自己的模型贴图。

## 开发环境

| 项目 | 版本 |
| --- | --- |
| Unity | 2022.3.62f3c1 |
| 渲染管线 | Built-in |
| 输入 | 旧版 Input Manager |

## 玩法与操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或方向键 |
| 瞄准 | 鼠标位置（角色朝向鼠标在地面的投影点） |
| 射击 | 鼠标左键（按住连发） |

## 目录结构

```
Assets/
├── Scenes/            主场景
├── Scripts/           自己写的脚本
│   ├── Player/        玩家移动、射击、血量
│   ├── Enemy/         怪物移动、攻击、血量
│   ├── Managers/      刷怪、计分、游戏结束
│   └── Camera/        摄像机跟随
├── Prefabs/           玩家、怪物、环境、特效预制体
├── Materials/ Animation/   材质与动画控制器
└── （Models/ Textures/ Audio/ Fonts/ _CompletedAssets/ 未随仓库提供）
```

## 运行方式

1. 用 Unity **2022.3.62f3c1** 或更新版本打开工程。
2. 打开 `Assets/Scenes` 下的主场景。
3. 点运行按钮即可游玩；`File > Build Settings` 里可以直接打包。

仓库只包含 `Assets/` 和 `ProjectSettings/`，`Library/`、`Temp/`、`Logs/` 等 Unity 自动生成的目录没有提交，首次打开工程时 Unity 会自己重建。
